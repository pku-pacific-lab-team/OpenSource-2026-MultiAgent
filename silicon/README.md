# Silicon: operating points, V-F-P curves and test programs

The chip is a 12 nm multi-agent LLM inference die used as a 2x2 chiplet
module (four identical dies). Each die integrates 32 INT cores and 8 FP cores
on a RISC-V CVA6 host; a digitally controlled oscillator (DCO) with 17
frequency codes supplies the core clock.

The frequency, current and power tables under `data/` are generated by a
model calibrated on the measurement campaign of the dies; their rows are
marked `model` in the `basis` column. The Vmin table and the min-power row
of the operating-point table are measured values.

## Directory

| Path | Content |
|---|---|
| `data/vf_curve_model.csv` | Supply sweep 0.55-1.00 V: frequency, internal voltage, current, power, throughput, efficiency, die-to-die bands |
| `data/operating_points.csv` | The three reported full-load operating points and the measured min-power mode |
| `data/vmin_distribution_measured.csv` | Minimum functional supply of the 44 measured dies |
| `test_programs/` | Bare-metal C programs, linker script, OpenOCD configurations and bench tools used in the testing |

## Units and columns

`data/vf_curve_model.csv` (one row per board supply voltage):

| Column | Unit | Meaning |
|---|---|---|
| `vdd_board_V` | V | supply set at the board |
| `f_light_load_MHz` | MHz | frequency capability at the board voltage without supply drop (CPU-spin load) |
| `f_full_load_MHz` | MHz | self-consistent frequency under full load (all 40 cores), after the supply drop |
| `f_full_load_die_min_MHz`, `f_full_load_die_max_MHz` | MHz | full-load frequency band across dies |
| `v_int_V` | V | internal supply after the board-to-core drop (`R_pdn` = 55 mOhm) |
| `i_die_mA`, `i_die_min_mA`, `i_die_max_mA` | mA | full-load current per die and its die-to-die band |
| `i_leak_die_mA` | mA | static current per die (f -> 0 intercept) |
| `p_die_mW`, `p_4die_mW` | mW | full-load power per die and for the four-die module (`V_board x I`) |

`data/operating_points.csv` uses the same columns plus `point` and `note`.
`data/vmin_distribution_measured.csv` lists the number of dies per Vmin value.

## Measurement method behind the parameters

- Bench: FC-BGA test board with a Rigol DP2031 supply (channel 2 = core
  rail, set in 40 mV steps with read-back), FTDI JTAG adapter driven by
  OpenOCD, GDB for loading and controlling the programs
  (`test_programs/openocd/`, `test_programs/tools/`).
- Per die and per voltage: the DCO is stepped through its 17 codes. At every
  code `vf_point.c` measures the clock with the cycle counter and runs the
  functional golden test; `scaling_pwr.c` then runs the all-40-core load while
  the supply current and the core voltage at the board are read three times
  and averaged. Vmin is the lowest supply at which all codes and the golden
  test pass; the Vmin search continues below the lowest grid point in 10 mV
  steps, which is why the Vmin table contains 0.53 V and 0.54 V.
- 44 dies within 11 packages were measured on the 18-point supply grid 0.55-1.20 V.

## Test programs

`test_programs/README.md` describes each program, the build flow (RISC-V GCC,
